# PathSnap HMM/Viterbi scripts

`hmm_decoder.py` contains the reusable Viterbi decoder and route metrics.
`run_hmm.py` joins the current candidate and LightGBM probability CSVs, audits
their alignment, decodes trips, and writes prediction and continuity files.

Run from the project folder:

```bash
python run_hmm.py
```

By default it processes only the permitted `student_test` partition and writes
to `hmm_outputs/`. Outputs are:

- `alignment_audit.csv`: candidate/probability overlap and coverage.
- `predictions.csv`: classifier-only and HMM arc predictions per GPS row.
- `route_continuity.csv`: direct connectivity, bounded reachability, and
  per-trip inference time.
- One `*_prediction_map.html` per trip if Folium is installed. Maps avoid
  external tile servers and show the local road graph, GPS observations,
  classifier route, HMM route, and provided reference route where available.

The decoder has no required third-party packages. Install Folium to generate
interactive maps:

```bash
python -m pip install -r requirements_hmm.txt
```

The score adapter matches on trip ID, observation index, and arc ID; restricts
exported scores to the generated candidate arcs; assigns `1e-12` to any candidate
arc with no matching score; then renormalizes within each observation. The
current train and student-test exports match every candidate arc (100% coverage),
so the fallback is unused in the current run. The scores are still normalized
before being used as HMM emissions.

## Decoder tuning and evaluation

Create route-aligned labels for training trips and tune only on LightGBM
out-of-fold training scores:

```bash
python align_student_test_labels.py --partition train
python tune_hmm.py
```

The tuning script searches a small, documented grid using mean per-trip Macro
F1. It excludes training trips with maximum route alignment distance over 250 m
or candidate miss rate over 10%, and records the exclusions and every trial in
`hmm_outputs/`. Apply the selected training-only parameters to student-test once:

```bash
python run_hmm.py --labels Dataset/student_test_observation_labels.csv \
  --max-hops 6 --meters-per-hop 80 --distance-tolerance-m 150 \
  --distance-scale-m 75 --disconnected-penalty -20
```

The resulting labels are derived by monotonically aligning observations to the
provided route sequence, so describe them as route-alignment-derived evaluation
labels, not independently verified ground truth.

The included `Dataset/*_observation_labels.csv` files are generated by
monotonically aligning GPS observations to the supplied `.route` sequence.
They are route-alignment-derived proxy labels, not independently verified
ground truth. Pass `--labels Dataset/student_test_observation_labels.csv` to
calculate Top-1 accuracy, Macro F1, candidate miss rate, and classifier log
loss. See `HMM_Report_Sections_5_6.md` for the results and limitations.

Useful options:

```bash
python run_hmm.py --partition student_test --maps none
python run_hmm.py --partition train --maps none
python run_hmm.py --gap-seconds 30 --max-hops 6 --meters-per-hop 80
```

The gap threshold is 30 seconds. The transition parameters above were selected
using training out-of-fold predictions only; student-test was used for the
reported development evaluation and not for tuning. Never use evaluator-test
data to tune parameters.
